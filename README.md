# Password Strength Checker

A beginner-friendly Python project that evaluates password strength using basic security rules.

## Overview

This project checks a password against several common security requirements and classifies it as **Weak**, **Medium**, or **Strong**.

The project was created as part of my learning journey in Python and cybersecurity fundamentals.

## Features

- Checks minimum password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Calculates a basic strength score
- Classifies passwords as Weak, Medium, or Strong

## Technologies

- Python 3
- Built-in Python functions
- Git & GitHub

## How It Works

The program asks the user to enter a password and performs several checks:

1. Password length
2. Uppercase character
3. Lowercase character
4. Numeric character
5. Special character

Each satisfied requirement contributes to the password's score.

The final score is used to classify the password strength.
